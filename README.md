# Cortexly website

A responsive single-page React website powered by Vite, with Home, Services, Pricing, Projects, Approach, About, and Contact sections. Use the navigation to smoothly scroll between sections.

## Run in VS Code

1. Install [Node.js](https://nodejs.org/) if it is not already installed.
2. Open the existing `agentra-website` project folder in VS Code. The website brand is Cortexly.
3. Open **Terminal > New Terminal**.
4. Run `npm install` once to install React, Vite, and Three.js.
5. Run `npm run dev` and open the local URL printed in the terminal.

## Production build

Run `npm run build`. Vite puts the optimized site in the `dist` folder. Use `npm run preview` to preview the build locally.
